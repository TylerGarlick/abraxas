### User Story
As an Epistemic Auditor, I want to label the origin of every claim (Direct, Inferred, or Artifact), so that I can prevent the "Lapping the Tracks" hallucination spiral by making training artifacts explicit and transparent.

### Description
Episteme is the "Glass Box" of the Sovereign Brain. It provides a knowledge-boundary mapping system that distinguishes between direct memory, retrieved knowledge, derived reasoning, and training-set artifacts. This ensures that the provenance of any claim is transparent and verifiable.

### Acceptance Criteria
- [ ] Implement the Episteme origin-mapping system (Direct, Inferred, Artifact).
- [ ] Create an audit trail that allows any claim to be traced back to its epistemic origin.
- [ ] Integrate with Mnemosyne retrieval logs and Logos reasoning chains to build a complete evidence map.
- [ ] Implement the `episteme trace`, `episteme audit`, and `episteme calibrate` commands.

### Implementation Notes
- Architecture: Two-tier Python implementation (FastMCP $\rightarrow$ EpistemeLogic).
- Role: Acts as the "Provenance Tracer" in the flow: Janus $\rightarrow$ Episteme $\rightarrow$ Ethos.

### Research Notes
