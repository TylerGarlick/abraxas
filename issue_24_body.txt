### User Story
As an AI Interoperability Engineer, I want to transition from local-first session frames to a Portable Epistemic Frame (PEF) specification, so that I can enable the secure and verified sharing of "truths" and context across different AI agents and systems.

### Description
Transition isolated session frames into a unified PEF envelope to enable the transfer of verified truths between agents. This allows an agent to 'inherit' the epistemic context of another without re-verifying every atomic claim.

### Acceptance Criteria
- [ ] Define the PEF envelope (Epistemic Content, Provenance, and Integrity hashes).
- [ ] Implement a "Handshake" modality for manual .pef file export/import.
- [ ] Research and prototype "Beam" (real-time agent-to-agent transfer).
- [ ] Explore "Truth-Net" using content-addressable storage (IPFS).
- [ ] Verify a truth transferred from one system (e.g., Claude) is correctly interpreted by another (e.g., Local Llama).

### Implementation Notes
- PEF must be content-hashed to ensure integrity during transfer.
- Focus on the envelope specification before the transfer modality.

### Research Notes
- Goal: Create a universal context layer that persists "truths" across any AI system.
