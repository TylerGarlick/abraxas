# SEO Optimizer Skill

**Triggers:** "SEO", "optimize SEO", "MJ SEO"

## Description
Analyzes content for SEO performance and provides optimization recommendations. Targets search intent, keyword placement, and readability.

## Usage
When user says "SEO", "optimize SEO", "MJ SEO", or similar phrasing:

1. Receive the content to optimize
2. Identify target keywords (or extract from content)
3. Analyze on-page SEO factors
4. Provide specific recommendations
