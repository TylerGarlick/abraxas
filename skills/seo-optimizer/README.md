# SEO Optimizer

Analyzes content for search engine optimization.

## Usage

```
You: "MJ SEO this blog post" [paste content]
MJ: Analyzes and provides SEO recommendations
```

## SEO Factors Analyzed

| Factor | Description |
|--------|-------------|
| Title | Length, keyword placement, power words |
| Meta Description | Length, compelling copy |
| Headers | H1-H6 structure, keyword usage |
| Keywords | Density, placement, variations |
| Links | Internal/external, anchor text |
| Readability | Flesch score, sentence length |

## Tips

- Provide target keyword if known
- Mention competing pages if relevant
- Review recommendations in context of search intent
