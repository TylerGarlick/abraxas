# Readability Scorer

Scores content readability.

## Usage

```
You: "MJ readability check this" [paste content]
MJ: Reports readability scores and suggestions
```

## Readability Metrics

| Metric | What It Measures |
|--------|-----------------|
| Flesch Reading Ease | Overall difficulty (0-100) |
| Gunning Fog Index | Years of education needed |
| SMOG Index | Grade level |
| Coleman-Liau | Character-based score |

## Score Interpretation

| Score | Level |
|-------|-------|
| 90-100 | 5th grade |
| 60-70 | 8th-10th grade |
| 30-60 | High school |
| 0-30 | College+ |

## Tips

- Target 60-70 for general web content
- Adjust based on your audience
- Short sentences generally score better
