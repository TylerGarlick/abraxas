# Style Guide Enforcer

Validates content against style guidelines.

## Usage

```
You: "MJ style check this article" [paste content]
MJ: Reports style violations with line numbers
```

## Style Rules Checked

| Category | Examples |
|----------|----------|
| Voice | Active vs passive, contractions |
| Terminology | Brand names, technical terms |
| Formatting | Headers, lists, punctuation |
| Length | Sentence, paragraph limits |

## Supported Guides

- AP Style (default)
- Chicago Manual of Style
- Custom house rules

## Tips

- Specify style guide if different from default
- Some rules are configurable
- Focus on consistency over prescription
