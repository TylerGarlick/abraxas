# Version Tracker

Tracks content versions and changes.

## Usage

```
You: "MJ track this" [paste content]
MJ: Logs version and returns tracking info
```

## Version States

| State | Description |
|-------|-------------|
| draft | Initial creation |
| review | Under editing |
| approved | Ready to publish |
| published | Live |
| archived | Superseded |

## Features

- Automatic timestamps
- Change summaries
- Version diffs
- Approval tracking

## Tips

- Use consistent content IDs
- Review version history before major edits
- Archive old versions to reduce noise
