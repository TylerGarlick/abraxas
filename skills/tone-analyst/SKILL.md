# Tone Analyst Skill

**Triggers:** "analyze tone", "MJ tone"

## Description
Analyzes the emotional tone and voice of written content. Identifies inconsistencies and provides guidance on achieving target tone.

## Usage
When user says "analyze tone", "MJ tone", or similar phrasing:

1. Analyze content tone across multiple dimensions
2. Identify tone inconsistencies
3. Compare against target tone if specified
4. Provide recommendations for adjustment
