# Tone Analyst

Analyzes content tone and voice.

## Usage

```
You: "MJ analyze tone" [paste content]
MJ: Reports on tone dimensions and consistency
```

## Tone Dimensions

| Dimension | Range |
|-----------|-------|
| Formality | Casual ← → Formal |
| Friendliness | Cold ← → Warm |
| Confidence | Hesitant ← → Certain |
| Urgency | Calm ← → Urgent |

## What Gets Analyzed

- Word choice patterns
- Sentence structure
- Emotional indicators
- Consistency across sections

## Tips

- Specify target tone if you have one
- Some variation is natural and healthy
- Brand voice should be intentional
