# Call to Action Writer

Crafts compelling CTAs.

## Usage

```
You: "MJ CTA for ebook download"
MJ: Generates multiple CTA options
```

## CTA Formulas

- **Action + Benefit:** "Get your free guide"
- **Urgency:** "Start now - limited time"
- **Question:** "Ready to transform?"
- **Command:** "Download your copy"

## Best Practices

| Element | Tip |
|---------|-----|
| Words | Use "you/your", action verbs |
| Length | 2-5 words for buttons |
| Contrast | Stand out from surroundings |
| Friction | Remove objections first |

## Tips

- Test multiple variations
- Match tone to content
- Consider urgency vs patience
