# Reporting Analyst

Generates reports from performance data.

## Usage

```
You: "MJ report on content performance"
MJ: Creates aggregated report with insights
```

## Report Types

| Type | Description |
|------|-------------|
| Performance | Views, engagement, conversion |
| SEO | Rankings, traffic, technical |
| Content | Inventory, gaps, effectiveness |
| Custom | Ad-hoc analysis |

## Tips

- Define the question before the report
- Include context (benchmarks, goals)
- Focus on actionable insights
