# Editor

Reviews and improves written content.

## Usage

```
You: "MJ edit this article" [paste content]
MJ: Reviews content and provides edited version
```

## Edit Modes

| Mode | Description |
|------|-------------|
| review | Highlights issues without changing |
| suggest | Proposes specific changes |
| apply | Makes edits directly |

## What Gets Edited

- Grammar and punctuation
- Sentence structure and flow
- Word choice and precision
- Consistency and tone
- Formatting issues

## Tips

- Specify edit mode if you have a preference
- Mention any style guide to follow
- Note if it's for a specific publication
