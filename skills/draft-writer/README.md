# Draft Writer

Quickly generates structured content drafts from brief prompts.

## Usage

```
You: "MJ draft - blog post about AI coding assistants"
MJ: Asks clarifying questions (audience, tone, length)
MJ: Generates structured draft with headlines and sections
```

## Supported Content Types

| Type | Description |
|------|-------------|
| Blog Post | SEO-optimized articles with headers |
| Article | Long-form content with citations |
| Email | Professional emails with subject lines |
| Landing Page | Conversion-focused copy |
| Social Post | Platform-specific formatting |

## Tips

- Be specific about audience and tone
- Request length guidance ("short", "medium", "detailed")
- Review draft against style guide before publishing
