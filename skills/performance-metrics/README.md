# Performance Metrics

Tracks and reports performance data.

## Usage

```
You: "MJ metrics for last month"
MJ: Shows performance dashboard
```

## Metrics Tracked

| Category | Examples |
|----------|----------|
| Content | Views, shares, engagement |
| Conversion | Leads, signups, purchases |
| SEO | Rankings, traffic, backlinks |
| Social | Followers, reach, engagement |

## Tips

- Set clear goals before tracking
- Compare periods for context
- Focus on actionable metrics
