# Content Calendar Skill

**Triggers:** "content calendar", "MJ calendar"

## Description
Plans and organizes content publishing schedule. Helps maintain consistent publishing cadence across platforms.

## Usage
When user says "content calendar", "MJ calendar", or similar phrasing:

1. Understand content goals and frequency
2. Map topics to dates/platforms
3. Create a balanced content mix
4. Export to calendar format
