# Content Calendar

Plans content publishing schedule.

## Usage

```
You: "MJ content calendar for April"
MJ: Creates a publishing schedule
```

## Content Mix

| Type | Frequency | Purpose |
|------|-----------|---------|
| Blog posts | Weekly | SEO, authority |
| Social | Daily | Engagement |
| Email | Bi-weekly | Nurture |
| Video | Monthly | Depth |

## Tips

- Batch content creation
- Balance promotional vs value
- Plan around events/holidays
- Leave room for real-time content
