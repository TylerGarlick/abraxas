# Editor Skill

**Triggers:** "edit", "MJ edit"

## Description
Reviews and improves written content for clarity, grammar, flow, and impact. Provides actionable feedback and can make direct revisions.

## Usage
When user says "edit", "MJ edit", or similar phrasing:

1. Receive the content to be edited
2. Analyze for grammar, clarity, flow, and engagement
3. Provide suggested edits with explanations
4. Apply edits if requested
