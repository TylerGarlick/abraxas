# Headline Analyzer

Evaluates headlines for effectiveness.

## Usage

```
You: "MJ headline check" [paste headline]
MJ: Scores and suggests improvements
```

## Scoring Dimensions

| Dimension | What It Measures |
|-----------|-----------------|
| Clarity | Immediately understandable |
| Impact | Memorable, powerful words |
| SEO | Keyword presence, length |
| Emotion | Psychological triggers |

## Headline Formulas

- How to [solve problem]
- [Number] ways to [achieve goal]
- [Adjective] + [noun] + [verb]
- Why [common belief] is wrong

## Tips

- Test multiple headlines
- Consider platform (SEO vs social)
- Numbers often improve CTR
