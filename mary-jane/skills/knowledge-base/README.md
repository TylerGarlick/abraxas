# Knowledge Base

Manages searchable institutional knowledge.

## Usage

```
You: "MJ KB add: brand voice guidelines"
MJ: Prompts for entry content, then saves

You: "MJ KB search: brand voice"
MJ: Returns matching entries
```

## Entry Types

| Type | Use Case |
|------|----------|
| Brand Guidelines | Voice, colors, terminology |
| Processes | How-to guides, workflows |
| Reference | Facts, data, specifications |
| Templates | Reusable content structures |

## Tips

- Use consistent tagging
- Link related entries
- Review for accuracy quarterly
