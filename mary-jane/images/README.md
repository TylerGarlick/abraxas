# Image Assets for Skill Router

## Required Images

Place the following images in this directory:

1. **architecture.png** - Full architecture flow diagram showing:
   - User Intent → Router → Registry → Scoring → Output
   - Decision tree for confidence thresholds

2. **scoring.png** - Scoring engine visualization:
   - Multi-factor matching breakdown
   - Weight distribution chart

3. **dispatcher.png** - Dispatcher mode flow:
   - How dispatch differs from explicit routing

## Image Guidelines

- Format: PNG or WebP preferred
- Size: Keep under 500KB each for fast loading
- Dimensions: 800x600 or similar aspect ratio for gallery consistency
- Use clear, readable fonts and contrasting colors

## How to Generate

You can create these diagrams using:
- Excalidraw (https://excalidraw.com)
- Draw.io (https://draw.io)
- Mermaid.js (can export to PNG)
- Any diagram tool of choice

Once created, place them in this `images/` folder and they'll automatically render in the README gallery.
