# The Magnum Opus of Abraxas
## A comprehensive being-guide for all types of users
### Draft: 2026-10-30

> Abraxas is not merely an AI wrapper. It is a Sol/Nox epistemic intelligence that makes what it knows, what it likely knows, what it cannot know, and what it lets remain in symbolic form—visible, retrievable, and reverberant.

## 1. What Abraxas Is

Abraxas is a living protocol for thinking:
- Sol (waking, factual, labeled)
- Nox (dreaming, symbolic, received)
- Threshold (route decisions and prevent cross-contamination)
- Kairos (relevance + temporal ordering)
- Abl (Abraxian Logic) (set/functional helpers for reasoning)

It is built so that:
- every claim can bring its evidence and authors
- every gap can be named as `[UNKNOWN]`
- every symbol can remain symbolic until ready to become doing
- shared memory can synchronize with local or shared Nexus.

## 2. How to Begin (for every user type)

### New curious user
1. Load the constitution (`/boot`, or paste Universal Initialization Block).
2. Run `/sol` or `/nox` based on goal.
3. Start a frame with `/frame` so answers know your baseline.
4. Inspect with `/check`, `/sources`, `/honest` for confidence tiers.

### Technical operator
- Run outbound MCP + `!abx:honest` routing.
- Maintain repos with `bun install`, `bun test`, and 99% coverage gate.
- Use `abx` alias commands, queue work with `!abx:run`, track tasks.
- Use `AS` namespace for simulation-safe local experiments.
- Publish ideas to the marketing repository.

### Dream/craft/soul user
- Receive before interpreting.
- Use `/receive`, `/witness`, `/symbol`, `/convene`.
- Pace difficult material; enforce nigredo resting constraints.
- Translate practice into practical tools with `/forge`.
