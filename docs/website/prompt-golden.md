# Abraxas Marketing Landing Page — Prompt (Golden)

## Goal
Build a single-page, marketing hero-driven landing page for Abraxas. Inform and educate visitors (developers/AI architects AND privacy/truth-seekers) on why Abraxas is the only way to get output you can trust, and move them to try it.

## Brand naming & naming rule
- Product name: Abraxas. Always title-cased. Use a special display font for "Abraxas" only.
- Tagline: "Truth is the best adventure."
- Forbidden word: "abrazas" (typo). Never use.

## Content source (derive, never verbatim)
- Pull substance from /docs and /research. Rewrite for marketing; never paste verbatim; <=2 short paragraphs + 3-5 bullets per section.
- Must cover: why named Abraxas, alchemical nature, "Truth is the best adventure."

## Audience split
- For Builders: deterministic PEF artifacts, provenance, portable state.
- For Truth-Seekers: ownership, no re-reasoning, local-first, calibrated confidence.

## Structure
1 Hero (special font name, promise, tagline, CTAs)
2 Why Abraxas / trust output — top 5 reasons
3 How systems work (PEF, provenance, confidence, local-first)
4 Examples of output (PEF/proof screenshots or text blocks)
5 Alchemical story
6 Footer: GitHub link, Docs link, support@hebros.us

## Top 5 reasons
- Portable truth across models
- Calibrated confidence intervals
- Mandatory provenance chain
- Local-first, sovereign
- Deterministic verification
