### User Story
As a Full-Stack Developer, I want to integrate Abraxas components with a JSON-backed GraphQL service, so that the "Edge" layer has a structured, single-endpoint access point to the Sovereign Graph.

### Description
The GraphQL server provides a flexible query layer for the Edge. By integrating Abraxas components with a JSON-backed service, we ensure that the Brain layer (MCP) can communicate effectively with the Edge without requiring direct database access.

### Acceptance Criteria
- [ ] Integrate Abraxas components with the `abraxas-graphql` service.
- [ ] Reconcile the in-repo `infra/api/graphql` implementation (either align or retire it).
- [ ] Expand the GraphQL schema to include types for `SVR_Evidence`, `ProvenanceChain`, and `RuptureForecast`.
- [ ] Verify that the system can run in a Codespace without an ArangoDB dependency for the GraphQL layer.

### Implementation Notes
- Canonical endpoint: `localhost:4000/graphql`.
- Architecture: Bedrock (DB) $\rightarrow$ Brain (MCP) $\rightarrow$ Edge (GraphQL).

### Research Notes
- GraphQL provides the flexibility needed for the Edge layer to query the complex Sovereign Graph.
