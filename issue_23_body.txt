### User Story
As a User, I want to receive a unified Sovereign Report instead of isolated skill outputs, so that I can get a high-density, definitive stance on a query that includes the evidence chain and a verified hash-linked receipt.

### Description
Transition isolated skill outputs into a unified Sovereign Report. A Sovereign Report is not a chat message; it is a high-density artifact that explicitly lists what is proven, what is suspected, and where the evidence fails.

- [ ] Integrate a hash-linked receipt for the entire reasoning chain.
