## Open Issues

### [ISSUE-001] Research and Implement Portable Epistemic Context (P2P)
- **Status:** Researching
- **Priority:** High
- **Description:** Transition from local-first session frames to a Portable Epistemic Frame (PEF) specification. 
- **Objectives:**
    - Define the PEF envelope (Epistemic Content, Provenance, Integrity).
    - Research P2P transfer modalities:
        - **Handshake:** Manual `.pef` file export/import.
        - **Beam:** Active real-time agent-to-agent transfer.
        - **Truth-Net:** Content-addressable distributed storage (IPFS).
    - Verify cross-system compatibility (e.g., Claude $\to$ Local Llama).
- **Goal:** Create a universal context layer that persists "truths" across any AI system.
