## Prognosis System

### What Prognosis Is
Prognosis is the predictive layer of the Sovereign Brain. It does not merely react to signals — it forecasts where the next signal will come from, grounded in the Conceptual Graph (Synesis) and Hardened Truths (v4.3). Named for the Greek *prognosis* (πρόγνωσις) — foreknowledge.

### The Core Principle: Grounded Forecasting
Every forecast must be grounded in $\geq 2$ Hardened Truths. Forecasts are not guesses — they are extrapolations from verified structural patterns.
- **Confidence expressed as probability intervals** (Dianoia integration).
- **Every forecast must be resolvable** — tracked to actual outcome via Aletheia.

### Commands

| Command | Function | Behavior |
|:---|:---|:---|
| `/prognosis forecast {domain}` | **Rupture Forecasting** | Predicts an epistemic collapse in the specified domain using hardened data. |
| `/prognosis signal {domain}` | **Signal Anticipation** | Ranks predicted locations of the next high-valence signal. |
| `/prognosis calibrate {id} {outcome}` | **Calibration Loop** | Resolves a forecast against reality and updates sovereign calibration. |
