## Metanoia System

### What Metanoia Is
Metanoia is the recursive evolution layer of the Sovereign Brain. It analyzes the system's own cognitive architecture to identify weaknesses, evolve parameters, and optimize the reasoning pipeline. Named for the Greek *metanoia* (μετάνοια) — transformation of mind, a fundamental change in thinking.

### The Core Principle: Self-Awareness
Metanoia operates on a strict audit-first protocol:
1. **Identify** weakness patterns (self-audit).
2. **Propose** parameter or structural changes (evolution).
3. **Log** all changes immutably (ledger).
4. **Rollback** is always available (previous state preserved).

### Commands

| Command | Function | Behavior |
|:---|:---|:---|
| `/metanoia agon audit` | **Auto-Agon Self-Audit** | Analyzes current stress-test parameters for weakness patterns and blind spots. |
| `/metanoia agon evolve {target}` | **Auto-Agon Evolution** | Autonomously evolves identified parameters with before/after logging. |
| `/metanoia harmonia audit {id}` | **Harmonia DAG Audit** | Analyzes a composition DAG for bottlenecks and redundancy. |
| `/metanoia harmonia refine {id}` | **Harmonia DAG Refinement** | Proposes DAG restructuring with quantified efficiency delta. |
