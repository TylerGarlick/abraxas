### User Story
As an AI System Architect, I want to verify the factuality of LLM outputs by comparing epistemic labels and consensus across multiple models, so that I can pinpoint and eliminate hallucinatory content.

### Description
The Cross-Model Epistemic Arbitration (CMEA) feature leverages the diverse epistemic lenses of multiple LLMs to verify generated content. Instead of trusting a single model's confidence, CMEA decomposes responses into atomic claims and arbitrates the truth based on cross-model consensus and epistemic labeling.

### Detailed Requirements
1. **Atomic Decomposition**
   - Implement a pipeline using `mcp__abraxas__logos_process_claim` to break primary model responses into a set of atomic propositions $\{P_1, P_2, ..., P_n\}$.
2. **Multi-Model Probing**
   - Orchestrate calls to $ independent models for each claim.
   - Collect: Truth Value (True/False/Unknown), Confidence Score, Epistemic Label (Empirical, Theoretical, etc.), and Provenance.
3. **Epistemic Mapping & Arbitration**
   - Generate a divergence matrix of atoms vs. models.
   - Calculate weighted agreement using `mcp__abraxas__compute_consensus` or `mcp__abraxas__logos_aggregate_evidence`.
   - Apply model weights via `mcp__abraxas__ethos_score` based on the epistemic domain.
4. **Hallucination Localization**
   - Flag claims with low aggregate confidence or high truth-value variance.
   - Map flagged claims back to original character offsets in the source text.
   - Visualize the contrast between the hallucinated span and the arbitrated truth.

### Technical Integration
- **Decomposition**: `mcp__abraxas__logos_process_claim`
- **Trust Weighting**: `mcp__abraxas__ethos_score` / `mcp__abraxas__source_reliability_update`
- **Aggregation**: `mcp__abraxas__logos_aggregate_evidence` / `mcp__abraxas__compute_consensus`
- **Provenance**: `mcp__abraxas__core_provenance_chain`
- **Truth Recording**: `mcp__abraxas__aletheia_confirm` / `mcp__abraxas__aletheia_disconfirm`

### Acceptance Criteria
- [ ] System can decompose a response into atomic claims.
- [ ] System collects labels and confidence from at least 3 different models.
- [ ] Arbitrated truth value is calculated using reliability-weighted consensus.
- [ ] The UI/Output can highlight the specific text spans that are identified as hallucinations.
